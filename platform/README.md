# Ali Saber System — Zero-Cost Platform

هذه النسخة لا تعتمد على Cloud Functions. لوحة الإدارة تعمل مباشرة عبر Firebase Web SDK وتتحقق من `platformAdmin` custom claim.

اقرأ `ZERO_COST_GUIDE_AR.md` قبل النشر. إعداد Firebase المستخدم هنا منفصل عن إعداد الإنتاج.


### إدارة الورش الذكية (v1.5.6)
تعرض لوحة المنصة حالة الورشة من خلال الجمع بين `platform/tenantDirectory/{tenantId}/status` و`platformBilling/{tenantId}/status`. تظهر الورشة التجريبية كـ«نشطة · فترة تجريبية»، وتظهر ورشة الاشتراك النشط كـ«نشطة». لا يظهر إلا الإجراء المناسب للحالة الحالية: «إيقاف الورشة» أو «تفعيل الورشة». حالات الإغلاق لا تعرض إجراء تفعيل مباشر. تتطلب كل عملية تأكيداً، وتعطل الزر أثناء الحفظ، ثم تعيد قراءة الحالة من Firebase. تتضمن القائمة بحثاً بالاسم أو Tenant ID أو Owner UID وفلترة حسب الحالة ومؤشرات إجمالية.
